# Chrome浏览器安全插件

一个集恶意URL检测、XSS防护、隐私追踪阻止于一体的Chrome浏览器安全插件，为用户提供全方位的网页浏览安全保护。

## 功能特性

### 🔗 恶意URL检测
- 实时检测用户访问的URL是否在已知恶意网站列表中
- 支持多种威胁类型检测：
  - 网络钓鱼网站
  - 恶意软件分发站点
  - 诈骗网站
  - 命令与控制服务器
- 支持Google Safe Browsing API集成（需要API密钥）
- 本地恶意URL缓存数据库
- 访问恶意网站前显示红色警告页面

### 🛡️ XSS防护
- 实时监控页面脚本执行
- 检测潜在的XSS攻击向量：
  - 可疑的innerHTML操作
  - 未经处理的用户输入直接插入DOM
  - 可疑的eval()函数调用
  - 异常的跨站请求
- 自动阻止已知的XSS攻击模式
- 可配置防护级别（标准/严格/自定义）
- 记录和报告被阻止的XSS尝试

### 🚫 隐私追踪阻止
- 阻止多种追踪器：
  - 广告追踪器（Google Analytics、Facebook Pixel等）
  - 社交媒体追踪器
  - 数据收集脚本
  - 指纹识别脚本
- 第三方Cookie阻止
- Canvas指纹识别防护
- WebRTC IP泄漏防护

## 在Chrome中部署插件

### 方法一：开发者模式加载（推荐用于开发和测试）

1. **准备插件文件**
   - 确保所有插件文件都在 `chrome-plugin` 文件夹中
   - 确保文件结构完整

2. **打开Chrome扩展管理页面**
   - 打开Chrome浏览器
   - 在地址栏输入：`chrome://extensions/`
   - 或者通过菜单：更多工具 → 扩展程序

3. **启用开发者模式**
   - 在扩展程序页面右上角，找到"开发者模式"开关
   - 点击开关，启用开发者模式

4. **加载插件**
   - 点击"加载已解压的扩展程序"按钮
   - 在弹出的文件选择对话框中，选择 `chrome-plugin` 文件夹
   - 点击"选择文件夹"或"选择"

5. **验证安装**
   - 插件应该出现在扩展程序列表中
   - 浏览器工具栏应该显示插件图标
   - 点击图标可以打开弹出窗口

6. **检查错误**
   - 如果插件没有正常加载，检查扩展程序页面是否有错误提示
   - 点击"错误"按钮查看详细错误信息
   - 常见问题：
     - manifest.json格式错误
     - 文件路径不正确
     - 缺少必要的权限声明

### 方法二：打包为.crx文件（用于分发）

1. **打包插件**
   - 在扩展程序页面，点击"打包扩展程序"
   - 选择扩展程序根目录：浏览到 `chrome-plugin` 文件夹
   - （可选）选择私钥文件，如果是首次打包可以留空
   - 点击"打包扩展程序"

2. **安装.crx文件**
   - 打包完成后会生成 `.crx` 文件和 `.pem` 私钥文件
   - 将 `.crx` 文件拖拽到扩展程序页面即可安装
   - 或者右键 `.crx` 文件 → 打开方式 → 选择Chrome

### 常见问题解决

#### 1. 插件无法加载
- **问题**：点击"加载已解压的扩展程序"后没有任何反应
- **解决**：
  - 确保选择了正确的文件夹（包含manifest.json的文件夹）
  - 检查manifest.json格式是否正确（JSON格式）
  - 查看浏览器控制台是否有错误信息

#### 2. 权限错误
- **问题**：插件功能不工作，提示权限错误
- **解决**：
  - 检查manifest.json中的permissions配置
  - 某些功能需要特定的权限，确保已正确声明

#### 3. Content Script未执行
- **问题**：内容脚本（XSS检测、追踪阻止等）不工作
- **解决**：
  - 检查manifest.json中content_scripts配置
  - 确保matches字段包含了目标网站
  - 检查JavaScript文件路径是否正确

#### 4. 图标不显示
- **问题**：插件图标显示为默认图标或空白
- **解决**：
  - 确保assets/icons文件夹中存在图标文件
  - 检查图标文件格式是否为PNG
  - 确保图标尺寸正确（16x16, 48x48, 128x128）

#### 5. Popup窗口无法打开
- **问题**：点击插件图标没有反应
- **解决**：
  - 检查popup/popup.html文件是否存在
  - 检查manifest.json中action.default_popup路径是否正确
  - 打开Chrome开发者工具查看控制台错误

## 使用说明

### 首次使用

1. **安装插件后**
   - 点击浏览器工具栏中的插件图标
   - 查看当前页面安全状态
   - 访问设置页面进行配置

2. **配置插件**
   - 点击插件图标，然后点击右上角的设置按钮
   - 或右键点击插件图标 → 选项
   - 在设置页面中配置各项功能

3. **白名单管理**
   - 在设置页面的"白名单管理"部分
   - 添加信任的网站域名
   - 白名单中的网站将不会被拦截

### 日常使用

- **查看安全状态**：点击插件图标查看当前页面安全状态
- **快速扫描**：点击弹出窗口中的"扫描当前页面"按钮
- **功能开关**：在弹出窗口中快速开启/关闭各项保护功能
- **查看统计**：在设置页面查看安全统计数据

### 功能开关说明

- **URL检测**：启用后会自动检测访问的URL是否为恶意网站
- **XSS防护**：启用后会在页面中监控并阻止XSS攻击
- **追踪阻止**：启用后会阻止页面中的追踪器和隐私收集脚本

## 性能要求

- 页面加载延迟增加不超过10%
- 内存占用控制在50MB以内
- CPU使用率在正常浏览时不超过5%

## 隐私保护

- 不收集用户浏览历史
- 所有URL检查在本地或通过加密API进行
- 提供匿名化的威胁报告选项
- 所有数据存储在本地，不会上传到服务器

## 技术栈

- **Manifest V3**：使用最新的Chrome扩展API
- **JavaScript ES6+**：现代JavaScript语法
- **Chrome Storage API**：本地数据存储
- **Chrome WebRequest API**：网络请求拦截
- **Content Scripts**：页面内容注入和监控

## 开发说明

### 修改配置

1. **添加恶意URL**：编辑 `background.js` 中的 `MALICIOUS_URLS` 数组
2. **添加追踪器域名**：编辑 `background.js` 中的 `TRACKER_DOMAINS` 数组
3. **修改默认配置**：编辑 `background.js` 中的 `DEFAULT_CONFIG` 对象

### 调试

1. **后台脚本调试**：
   - 在扩展程序页面，找到插件
   - 点击"service worker"链接打开后台脚本调试器

2. **Content Script调试**：
   - 在目标网页中打开开发者工具（F12）
   - 在Console标签中可以看到content script的日志

3. **Popup调试**：
   - 右键点击插件图标 → 检查弹出内容
   - 或点击弹出窗口，然后按F12

### 测试

1. **功能测试**：
   - 访问已知的恶意URL测试URL检测功能
   - 在网页中注入XSS代码测试XSS防护功能
   - 访问包含追踪器的网站测试追踪阻止功能

2. **性能测试**：
   - 使用Chrome DevTools的Performance工具
   - 监控页面加载时间和资源使用
