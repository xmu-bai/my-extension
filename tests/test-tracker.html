🔒 Tracker Blocker Test Page

此页面用于验证浏览器扩展的追踪器阻止功能。所有测试结果会在下方实时显示。

ℹ️ 使用说明

  1. 打开此页面，所有测试会自动运行。
  2. 打开 浏览器开发者工具（F12）的 Network 标签页，观察请求是否被阻止（显示 Blocked by client）。
  3. 同时观察 Console 标签页，查看页面或扩展的日志信息。
  4. 查看 Service Worker 控制台（chrome://extensions -> 扩展 -> "Service Worker (inspect views)"），观察后台日志。
  5. 点击下方按钮触发更多测试。

1️⃣ 外部追踪脚本加载测试

尝试动态加载来自 google-analytics.com 的脚本。

2️⃣ Fetch 请求测试

尝试 fetch 请求到常见追踪端点。

3️⃣ XMLHttpRequest 测试

尝试 XHR 请求到常见追踪端点。

4️⃣ Navigator.sendBeacon 测试

尝试用 navigator.sendBeacon 向追踪端点发送数据。

5️⃣ 图片资源测试

尝试加载来自追踪域名的图片（1x1 像素追踪 pixel）。
